# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.x     | Yes       |
| 1.x     | No        |

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately, either through GitHub's [private vulnerability reporting](https://github.com/wovosoft/laravel-uniexporter/security/advisories/new) or by email to [wovosoft@gmail.com](mailto:wovosoft@gmail.com).

Include the affected version, how to reproduce the problem and its impact. You will get a reply within a week; once the issue is confirmed, a fix is released and the advisory is published with credit to the reporter, unless you prefer otherwise.
